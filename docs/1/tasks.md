## Task 5: Add Problem wizard — problem input and 5 Whys flow

**Description**
Build the multi-step wizard: step 0 captures the problem description; steps 1–5 are the 5 Whys loop. Each why step shows the current level, a textarea, a "Next" button, and a "Skip" button. A progress indicator ("Why 2 of 5") is shown throughout. Completing step 5 advances to the root cause selection screen.

**Acceptance Criteria**
- [ ] Step 0: text input for problem description; "Start 5 Whys" is disabled until text is entered
- [ ] Steps 1–5: each shows "Why N of 5", a textarea, "Next" (disabled if empty) and "Skip"
- [ ] Skipping records `{ text: '', skipped: true, isActionableRootCause: false }` and advances
- [ ] Answering records `{ text, skipped: false, isActionableRootCause: false }` and advances
- [ ] After step 5, transitions to the root cause selection step (Task 6 component)
- [ ] In-progress wizard state held in component state (not yet persisted)

**Files Likely Affected**
- `src/pages/AddProblem.tsx` — new (wizard shell + step 0)
- `src/components/WhyStep.tsx` — new (steps 1–5)

**Test Requirements**
- Manual: complete full flow; skip all; mix of answers and skips

**Dependencies**
- Depends on Tasks 2, 3

**Estimated Complexity:** M

## Task 7: Problem detail — SVG tree view

**Description**
Build the `ProblemDetail` page and `ProblemTree` component. The tree renders the problem description as the root node at the top, with each why answer as a child node below it, connected by vertical SVG lines. Answered nodes are white/neutral; skipped nodes are grey/muted; actionable root cause nodes have an amber border and a "Root Cause" badge. A "Back" button returns to Home.

**Acceptance Criteria**
- [ ] Problem description node appears at the top-centre
- [ ] 5 why-answer nodes appear below in sequence, each connected to the node above by a vertical line
- [ ] Skipped nodes are visually distinct (grey, italic or muted)
- [ ] Actionable root cause nodes have an amber/highlighted border and a visible badge or label
- [ ] "Back" button navigates back to Home
- [ ] Tree is readable on a standard laptop screen (1280 px wide)

**Files Likely Affected**
- `src/pages/ProblemDetail.tsx` — new
- `src/components/ProblemTree.tsx` — new (SVG tree renderer)

**Test Requirements**
- Manual: open a problem with mixed answers; verify visual correctness of all node states
